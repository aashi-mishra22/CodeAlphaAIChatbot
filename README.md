                             AI ChatBot using Java

                             Project Description

This project is an AI ChatBot developed using Java as part of the CodeAlpha Java Programming Internship.

The chatbot uses Basic Natural Language Processing (NLP) techniques such as text preprocessing, tokenization, keyword extraction, and rule-based response generation to interact with users in real time.

A Java Swing GUI provides an interactive chat interface where users can communicate with the chatbot easily.

---

                                 Features

- Interactive Java Swing GUI
- Real-time chat interaction
- Basic NLP preprocessing
  - Lowercase conversion
  - Punctuation removal
  - Tokenization
  - Stop-word removal
- Rule-Based AI response engine
- Programming-related knowledge
- Current Date and Time
- Random programming jokes
- Greeting and farewell responses
- Object-Oriented Programming (OOP) design
- Modular and maintainable code

---

                               Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- Natural Language Processing (Basic NLP)
- Rule-Based Artificial Intelligence
- Java Collections Framework

                               AI Logic Used

The chatbot follows a Rule-Based AI approach. After preprocessing the user's input using NLP techniques, keywords are extracted and matched against predefined rules to generate an appropriate response.
